### 👨‍💻 Sobre mim

Sou **Thiago Viana**, estudante de tecnologia, explorando o desenvolvimento de aplicações, bancos de dados e o universo da análise de dados. Uso este espaço para documentar meu aprendizado e compartilhar projetos acadêmicos.

- 🎓 Estudando programação, desenvolvimento web e banco de dados.
- 🧩 Praticando **HTML, CSS, JavaScript, C e MySQL**.
- 📊 Interessado em **dados**, lógica e soluções úteis.
- 🎯 Objetivo: evoluir tecnicamente e construir um portfólio sólido.
